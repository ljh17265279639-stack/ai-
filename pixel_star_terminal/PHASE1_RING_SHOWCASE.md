# Phase 1.2 · Saturn Ring Showcase

This iteration changes only the visual background presentation.

- Saturn remains physically tilted at 26.73°.
- The camera is elevated substantially above the ring plane so the complete ring system opens into a broad ellipse.
- The lens is narrowed so the full ring system nearly fills a 1440×900 viewport without cropping.
- Mobile uses a separate, farther camera so the complete ring remains visible in portrait.
- Star density and opacity are reduced for a quieter, emptier black-space background.
- Top bar, navigation, panels, cards and instruments use lower-alpha glass surfaces with less blur so the ring remains visible beneath the UI.
- Form controls remain slightly denser to preserve text readability.

## Composition revision
- Desktop camera now uses an oblique elevated view (approx. 25° elevation plus lateral offset) chosen to keep the full outer ring inside 1440×900 while making the ring ellipse much more open.
- At the acceptance viewport, the outer ring spans roughly 92% of the available width, leaving only a narrow black-space margin.
- Mobile has its own farther oblique camera so the full ring remains inside 390×844.
- Glass surfaces were reduced another step in opacity and blur so the ring remains legible beneath the working UI.
