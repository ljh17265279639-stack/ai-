PIXEL STAR / Phase 1 - Saturn 3D Background

IMPORTANT
---------
Do NOT double-click index.html for local preview.
The site uses native ESM + importmap, and modern browsers block local module loading over file://.

FIRST LAUNCH
------------
1. Double-click START_PIXEL_STAR.cmd
2. On first launch it downloads Three.js + authentic Saturn textures to local folders.
3. It then starts a LOCAL STATIC FILE SERVER on 127.0.0.1:8123 and opens index.html automatically.
4. Keep the black terminal window open while using the site.

AFTER THE FIRST LAUNCH
----------------------
All runtime Three.js files and textures are local. The website itself uses no CDN, no application backend and no build step.

PRODUCTION / HOSTING
--------------------
index.html remains the entry point. Upload this folder to any normal static web host.
