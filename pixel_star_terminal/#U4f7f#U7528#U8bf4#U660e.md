# PIXEL STAR · 星舰总控台 v2.1

## 打开

1. 将整个压缩包解压到一个文件夹（不要在压缩包预览里直接打开）。
2. 双击 `index.html`。无需安装、联网、构建或启动服务。
3. `widget.html` 是配套的小组件页面。

字体、样式、程序与太空场景均在本地。请保留 css、js、fonts 三个文件夹与 HTML 的相对位置。

## 从旧版迁移

先在旧版「档案仓库」导出 JSON 备份，再打开新版，在「档案仓库」导入同一份备份。任务、分类、长期目标和排期沿用原来的数据结构。直接打开本地文件时，换目录或换浏览器可能会使用不同的数据空间，因此迁移时请使用导出/导入。

## v2.1 本次调整

1. 全屏太空背景延伸到顶栏与侧栏；顶栏和侧栏采用半透明玻璃质感。
2. 移除顶部独立的大幅舷窗框与占位；励志话语移至顶栏。
3. 顶栏大型像素时钟，显示本地时分秒、完整日期和中文星期；桌面大屏字号最高 96px。
4. 星球采用球面纹理自转，约 72 秒一圈，光照方向保持稳定；支持暂停动态和减少动态偏好。
5. 左上角换为原创像素火箭标志，包含舷窗、尾翼和轻微尾焰动画。
6. 日历日期详情改为原生日历上方的半透明悬浮窗；带横向扫描式展开/收起动画，不占网格布局空间。使用 ×、Esc 或点击面板外关闭，关闭后焦点返回所选日期。

已验证 1440 / 1024 / 768 / 390 / 320px 布局；日历弹窗前后网格宽度不变，桌面网格位置也不变。五个页面的自动文字对比度与控件名称检查通过，无脚本异常。

## 操作与可访问性

- 顶部「暂停动态」可暂停背景与装饰动画；遵循系统“减少动态效果”偏好。
- Tab 可在控件间移动；任务勾选框和日历日期支持 Enter / 空格。
- 焦点使用清晰的琥珀色外框；输入框具备可访问名称。
- 完成状态同时使用勾选符号、划线和文字，不只依赖颜色。
- 统计页提供「查看完成记录（文字版）」。
- 主要文字配色对比度：正文 13.66:1；次要文字 6.94:1；导航选中态 8.74:1；主按钮 11.64:1；分类标签 9.22:1。
- 已在 Chromium 检查五个页面的文字对比度、表单名称与按钮名称；测试状态中无相关自动检测违规。这不是对所有浏览器、全部状态的 WCAG 全项认证。

## v2.2 背景升级：真实木星

1. 背景星球由程序生成的像素行星，升级为 NASA/ESA 哈勃望远镜实拍木星全球地图（等距圆柱投影，来源：NASA SVS #12021 "Hubble Maps Jupiter in 4k"，OPAL 计划）。
2. 木星以 20° 倾角自转，约 60 秒一圈；采用三维球面映射 + 双线性纹理采样，光照方向固定，带气态巨行星临边增亮效果；外围保留一道极暗的薄环提示倾角。
3. 纹理以 base64 内嵌于 js/jupiter_tex.js，离线双击打开也能正常显示；若数据缺失会自动回退到程序纹理。
4. 今日舰桥的舰桥通讯会轮播 NASA 木星实测数据（直径、自转周期、大红斑等）。
