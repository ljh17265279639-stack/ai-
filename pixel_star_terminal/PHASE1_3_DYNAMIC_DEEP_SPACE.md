# PIXEL STAR · Phase 1.3 Dynamic Deep Space

本阶段在 Phase 1.2 Reference Lock 基础上，仅增加动态，不改变已锁定的土星构图、镜头和星环视觉。

## 动态土星
- 土星球体沿自身轴自转：120 秒 / 圈。
- 星环本体不作为刚体高速旋转，避免塑料模型感。
- 仅加入极稀疏的环粒子层，以 210 秒 / 圈缓慢运动，强化环系是轨道粒子系统的感觉。

## 深空背景
- 不使用星云贴图、银河背景图或视频。
- 三层实时 3D 星点，分别处于远 / 中 / 近距离。
- 各层数量、尺寸、亮度不同，形成纵深。
- 各层以极慢且不同方向的角速度漂移，形成轻微视差。
- 极轻微整体明暗呼吸，避免静态壁纸感。

## 动态可访问性
- respects `prefers-reduced-motion: reduce`。
- 网站原有“暂停动态”事件会同时暂停：土星自转、星环粒子、深空漂移。

## 不变项
- Phase 1.2 已锁定的土星大小、镜头角度、星环展开、环材质、UI 透明方案不变。
